AWS Biographer

Memory in CockroachDB · read-only against AWS · —
biographer
I answer questions about this AWS account from durable memory in CockroachDB, and I remember what you tell me. Every answer that names a resource carries an ARN or an identifier you can paste into the console. I cannot change anything in AWS — that boundary is in IAM, not in my prompt. This demo runs against a deliberately messy seeded account.
